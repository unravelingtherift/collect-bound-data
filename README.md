# collect-bound-data

Data and assets for **Unraveling the Rift** ([unravelingtherift.com](https://unravelingtherift.com)):
the Collection-Bound tracker, the Riftbound Starter Handbook and the Lore Codex.

These files are public only so the website can load them. They are **not open data**:
copying, scraping or reusing the compiled card, product and regional-variant data to
build another site, app or dataset is not permitted. See [LICENSE](LICENSE).

Riftbound and League of Legends are trademarks of Riot Games; card text and images
© Riot Games. Unraveling the Rift is not endorsed or sponsored by Riot Games.

## What's here

| Path | What it is |
| --- | --- |
| `ogn.json`, `ogs.json`, `sfd.json`, `unl.json`, `ven.json` | Card lists per set |
| `products.json` | Sealed Riftbound products, per language |
| `cardtext.json` | Card text and regional image sources |
| `market-tools/` | Market comparison and landed-cost module for the tracker |
| `handbook/`, `handbook-images/` | Starter Handbook |
| `codex/` | Lore Codex |
| `branding/` | Logos |
