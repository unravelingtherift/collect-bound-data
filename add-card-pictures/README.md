# Add or replace a card picture

1. Name the picture: **set - card number - language**, for example `OGN-006-zh.png`.
   - Languages: `en` English, `zh` Chinese, `fr` French, `ko` Korean.
   - Alternate art: add the letter, like `OGN-112a-zh.png`. Signature (`*`) cards: `SFD-233star-zh.png`.
2. In this folder on GitHub, click **Add file → Upload files** and drag the pictures in.
3. Click **Propose changes**, then **Create pull request**, then **Merge pull request**.

A few minutes later the pictures are on the tracker. White corners are trimmed automatically.
To replace a picture, upload a new one with the same name.
To check it worked: **Actions** tab → **Add card pictures** → the newest run lists each picture.
